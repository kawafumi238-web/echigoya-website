Echigoya Stock Analysis

Personal Japanese Stock Market Research System

Privacy Policy

About This Application

Echigoya Stock Analysis is a private application designed for personal stock market research, financial data analysis, and paper trading.

Google Drive integration is used to store, retrieve, and update research data and reports in the application owner's Google Drive.

This application is not offered as a public investment or trading service.

Privacy Policy

Effective date: November 25, 2026

Data Access

The application uses Google OAuth to access Google Drive files for personal financial research and automated report generation.

Data Usage

Google user data is used solely to provide the application's research, storage, and reporting functions.

Data Sharing

Google user data is not sold or used for advertising. Authorized cloud infrastructure, including GitHub Actions, may process data to perform automated research tasks.

Data Security

Authentication credentials are intended to be stored securely using private credential storage. Research data is not intentionally published on this website.

Data Retention and Deletion

The application owner controls the research files and may delete them from Google Drive. Access can be revoked through Google Account security settings.

Google API Compliance

The application will use Google API data in accordance with the Google API Services User Data Policy, including applicable Limited Use requirements.

Contact

For privacy-related inquiries, contact the application owner through the support email listed on the Google OAuth consent screen.
